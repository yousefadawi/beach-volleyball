# كرة الشاطئ 🏐

لعبة كرة طائرة شاطئية بمنظور علوي، تشتغل على الجوال كتطبيق (PWA).

## النشر على GitHub Pages
1. أنشئ مستودع جديد على GitHub (مثلاً `beach-volleyball`).
2. ارفع كل الملفات الموجودة هون (index.html, manifest.json, sw.js, الأيقونتين icon-192.png و icon-512.png).
3. من Settings ← Pages ← Source: اختر `Deploy from a branch` والفرع `main` والمجلد `/ (root)`.
4. بعد دقيقة بيطلع الرابط: `https://USERNAME.github.io/beach-volleyball/`

## تثبيته كتطبيق
- **أندرويد (Chrome):** افتح الرابط ← القائمة ⋮ ← "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية".
- **آيفون (Safari):** افتح الرابط ← زر المشاركة ← "إضافة إلى الشاشة الرئيسية".

بعد أول فتح بتشتغل اللعبة بدون إنترنت.

## لتحديث اللعبة لاحقاً
غيّر قيمة `V` في sw.js (مثلاً `beach-v2`) عشان الجوال ياخذ النسخة الجديدة.
